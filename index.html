About

About Lapa Studio

A small, independent studio named after Lapa, our curious and ever-sleepy cat. We build our own mobile products and partner on select projects where we can bring real value with design, development and care.

We build with Kotlin Multiplatform and Compose Multiplatform: shared code where it saves time, native where it helps. Performance, privacy and the store requirements are part of the work from the first day, not a task for the week before release.
